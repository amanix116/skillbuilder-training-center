## 📊 Database Schema

### admins
- id (PK, AUTO_INCREMENT)
- email (VARCHAR, UNIQUE)
- password (VARCHAR, hashed)

### courses
- id (PK, AUTO_INCREMENT)
- title (VARCHAR)
- description (TEXT)
- duration (VARCHAR)
- price (DECIMAL)

### applications
- id (PK, AUTO_INCREMENT)
- full_name (VARCHAR)
- email (VARCHAR)
- phone (VARCHAR)
- course_id (FK)
- message (TEXT)
- created_at (TIMESTAMP)

### trainers
- id (PK, AUTO_INCREMENT)
- name (VARCHAR)
- role (VARCHAR)
- photo (LONGTEXT)

### contacts
- id (PK, AUTO_INCREMENT)
- name (VARCHAR)
- email (VARCHAR)
- message (TEXT)
- created_at (TIMESTAMP)
